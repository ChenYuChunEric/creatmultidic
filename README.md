# 批次資料夾建立工具 (Batch Folder Creator)

一個輕量、模組化且具備 GUI 圖形介面與 CLI 命令列介面的 Python 批次資料夾建立工具。無需安裝任何第三方套件，完全基於 Python 3 標準函式庫。

---

## 🌟 核心功能特色

1. **獨立 GUI 視窗介面（免開 PowerShell / CMD）**
   - 直覺的分頁頁籤設計、路徑選取器與即時執行結果日誌。
   - 雙擊即可開啟應用程式視窗，無黑色控制台干擾。

2. **指定輸出路徑 (目標資料夾)**
   - 支援 GUI 點擊「📁 瀏覽」按鈕直接選取資料夾。
   - 若指定路徑不存在，程式自動建立該父目錄。

3. **自訂名稱批次建立**
   - 支援一次輸入多個名稱（使用逗號、頓號或換行分隔），批次自動建立對應資料夾。

4. **流水號組合命名**
   - 支援特定名稱與數字流水號組合（如 `01_專案` 或 `專案_01`）。
   - 靈活設定「流水號在前」或「名稱在前」。
   - 可自訂起始號碼、建立數量、分隔符號以及補零位數（如 2 位 `01`、3 位 `001`）。

5. **週次與日期區間命名**
   - 指定起始日期（如 `2026-08-03`）與總週數，自動計算與生成每週區間。
   - 自動將週次轉換為中文數字，輸出格式如：`1.第一周(0803-0809)`、`2.第二周(0810-0816)`。

6. **容錯與提示處理**
   - 資料夾已存在時不會報錯中斷，於介面日誌清楚標示「🟢 建立成功」、「🟡 已存在」或「🔴 失敗」。

## 📁 專案目錄結構

```text
batch_folder_creator/
├── gui.py                  # GUI 圖形介面主程式 (Tkinter 質感視窗)
├── gui.pyw                 # GUI 無控制台直接啟動檔
├── run_gui.bat             # 雙擊直接啟動 GUI 視窗批次檔
├── folder_creator.py       # 核心邏輯 Class (FolderCreator)
├── main.py                 # CLI 互動式主選單介面
├── test_folder_creator.py  # 自動化單元測試腳本
└── README.md               # 專案說明文件
```

---

## 🚀 快速開始與使用說明

### 方式一：開啟 GUI 圖形視窗介面 (推薦 ⭐)

- **雙擊執行**：直接滑鼠雙擊資料夾內的 `run_gui.bat` 或 `gui.pyw` 檔案，即可直接開啟視窗介面！
- **指令執行**：
  ```bash
  python gui.py
  ```

---

### 方式二：使用 CLI 文字選單介面

在終端機中執行：

```bash
python main.py
```

---

## 🧪 執行單元測試

執行以下指令驗證核心邏輯與轉換演算法：

```bash
python test_folder_creator.py
```
